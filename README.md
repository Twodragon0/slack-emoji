# Slack Emoji Collection

> Collection of custom Slack emojis and emoticons

## 📋 Overview

This repository contains a curated collection of custom Slack emojis, primarily featuring Pepe and other popular emoticons for use in Slack workspaces.

## 📁 Contents

### [pepe](./pepe/)

Collection of Pepe emojis in various formats (PNG, JPG).

## 🚀 Usage

### Adding Emojis to Slack

1. **Navigate to Slack Workspace Settings**
   - Go to your Slack workspace
   - Click on your workspace name → Settings & administration → Customize [workspace name]

2. **Upload Emoji**
   - Scroll to the "Emoji" section
   - Click "Add Custom Emoji"
   - Upload the emoji file
   - Set a name (e.g., `pepe_1`, `pepe_2`)
   - Click "Save"

3. **Use in Messages**
   ```
   :pepe_1:
   :pepe_2:
   ```

### Bulk Upload

For bulk uploads, you can use Slack's API or third-party tools:
- [Slack Emoji Tools](https://github.com/slackhq/slack-emoji-tools)
- [Emoji Uploader Scripts](https://github.com/slack-ruby/slack-ruby-client)
